# FFXIV 資源站

> Final Fantasy XIV 中文資源整理，繁體中文台灣用語。

## 功能

### 🎰 仙人微彩求解器（Mini Cactpot Solver）

- 路徑：[`cactpot/index.html`](cactpot/index.html)
- 輸入遊戲內看到的數字，即時求解 3×3 仙人微彩
- **揭牌階段**：以最佳續玩遞迴推薦「下一格該翻哪裡」（最大化期望獎金）
- **選線階段**：填滿 4 格後鎖盤，推薦期望最高的連線，並以白話說明期望值
- 點任一連線可查看**完整機率分布**（各三數和的獎金與出現機率）
- 可回報實際選線與實得 MGP（存於本機瀏覽器），預留未來統計空間
- 含完整獎金對照表與使用說明

## 開發

本站為純靜態網站（HTML + CSS + JavaScript），無需安裝任何依賴，直接在瀏覽器開啟 `index.html` 即可使用。
